# Graph Neural Network for Product Recommendation on Amazon Co-purchase Graph

This repository contains the implementation of Graph Neural Networks for product recommendation on Amazon co-purchase graphs.

## Paper

Our paper has been published at: [https://arxiv.org/abs/2508.14059](https://arxiv.org/abs/2508.14059)

## Overview

This project implements various Graph Neural Network architectures for product recommendation systems, including:
- GraphSAGE
- GAT (Graph Attention Network)
- PinSAGE
- LightGCN

## Structure

- `notebooks/` - Jupyter notebooks for different models
- `scripts/` - Training and utility scripts
- `model/` - Pre-trained model files
- `data/` - Dataset files
- `results/` - Training results and logs
